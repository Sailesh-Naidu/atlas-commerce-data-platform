# CS-004: Exception Ownership

Status: Accepted

## Rule

Each layer is responsible for adding context to exceptions but should not
make recovery decisions outside its scope.

Lower layers may catch exceptions to:

- add diagnostic context
- translate implementation-specific exceptions into platform exceptions
- release resources

Exceptions that cannot be fully recovered from must be re-raised.

The job layer owns workflow-level decisions such as:

- retries
- pipeline termination
- alert generation
- recovery
- notification

## Rationale

Separating exception context from exception ownership improves:

- maintainability
- observability
- debugging
- architectural consistency

It also prevents lower-level components from making business decisions
they are not qualified to make.
