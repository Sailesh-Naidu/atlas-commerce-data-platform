# DS-002: Standardize on Google-Style Docstrings

Status: Accepted

## Rule

Atlas uses Google-style docstrings for all public modules, classes and
functions.

The standard structure includes:

- Summary
- Args
- Returns
- Raises
- Notes (when required)
- References (when applicable)

## Rationale

Google-style docstrings provide:

- consistent documentation
- excellent readability
- strong IDE support
- simple onboarding
- compatibility with documentation generators

The style balances completeness with clarity and is well suited for
long-term enterprise application development.

## Example

```python
def load_customer_snapshot(
    config: CustomerConfig,
) -> DataFrame:
    """
    Loads the latest customer snapshot from the configured source.

    Args:
        config: Customer ingestion configuration.

    Returns:
        Spark DataFrame containing the customer snapshot.

    Raises:
        StorageException:
            If the snapshot cannot be loaded.
    """
```
