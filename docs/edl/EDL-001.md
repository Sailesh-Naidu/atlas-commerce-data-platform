# EDL-001: Standardize on uv for Python Dependency Management

Status: Accepted

Date: 2026-08-03

---

## Context

Atlas is a long-term enterprise platform that will continue to evolve as
new technologies are introduced.

The project requires a modern dependency management solution that
supports reproducible environments, fast installation, virtual
environment management and consistent developer workflows.

---

## Decision

Atlas will standardize on **uv** for Python package management,
dependency installation and project execution.

All developers should use uv rather than pip for day-to-day development.

---

## Rationale

uv provides:

- significantly faster dependency resolution
- fast package installation
- integrated virtual environment management
- reproducible project environments
- simplified project execution
- compatibility with standard Python packaging

Using a single dependency manager ensures consistent environments across
all development stages.

---

## Trade-offs

Adopting uv introduces the following trade-offs:

- Developers unfamiliar with uv require a short learning period.
- Some legacy documentation and tutorials assume pip.
- Team members must standardize on the same tooling.

These trade-offs are considered acceptable because the benefits in
developer productivity and environment consistency outweigh the initial
learning effort.

---

## Review Trigger

Review this decision if:

- Python packaging standards change significantly.
- uv no longer meets project requirements.
- Enterprise deployment constraints require an alternative solution.
