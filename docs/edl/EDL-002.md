# EDL-002: Standardize on Ruff for Code Quality

Status: Accepted

Date: 2026-08-03

---

## Context

Atlas requires a consistent approach to code quality that can be applied
across all development environments.

The platform should automatically enforce coding standards rather than
relying on manual code reviews.

---

## Decision

Atlas will standardize on **Ruff** for:

- linting
- code formatting
- import organization

Ruff configuration will be maintained centrally in
`pyproject.toml`.

All developers and CI pipelines must use the same configuration.

---

## Rationale

Ruff provides:

- fast linting
- integrated code formatting
- import sorting
- centralized configuration
- consistent code quality
- reduced tooling complexity

Using a single tool minimizes configuration drift while ensuring that
every developer follows the same engineering standards.

---

## Trade-offs

Adopting Ruff introduces the following trade-offs:

- Developers must follow standardized formatting rules.
- Existing code may require automatic reformatting.
- Some highly customized linting rules may not be enabled initially.

These trade-offs are acceptable because they improve long-term
maintainability and consistency.

---

## Review Trigger

Review this decision if:

- project requirements exceed Ruff capabilities
- the Python ecosystem introduces a significantly better alternative
- Atlas requires additional static analysis beyond Ruff
