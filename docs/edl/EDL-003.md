# EDL-003: Ruff Enforcement Strategy

**Status:** Accepted  
**Date:** 2026-08-03

## Context

Atlas requires consistent code quality enforcement across local
development and future CI/CD workflows.

Ruff will be used for linting, formatting, and import organization, but
the enforcement approach should evolve gradually while the initial
configuration is still being stabilized.

## Decision

Atlas will use a staged Ruff enforcement strategy.

### Stage 1 — Manual Execution

During initial repository setup, developers will run Ruff manually:

```bash
uv run ruff check .
uv run ruff format --check .
